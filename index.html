A marca

A Genesis Consulting entrega valor imediato: mais do que implementar soluções, oferecemos consultoria em TI voltada a resolver os desafios críticos do negócio. Esta identidade é dark-first — a superfície quase-preta domina e o verde aparece como pontuação funcional, nunca como área.

Logo

Sobre superfícies escuras — a maioria neste sistema — use a versão branca. A colorida é exclusiva de fundos brancos ou claros. O módulo é escolhido pelo local de aplicação, nunca por gosto.

Área de respiro

1X — a altura do símbolo. Nenhum elemento invade essa zona. 0,5X é tolerado apenas em layout móvel denso.

Redução mínima

32px para o lockup horizontal · 64px para o vertical (Slogan) · 16px para o monograma isolado.

Nunca

Distorcer, rotacionar, recolorir fora dos temas, aplicar sombra ou contorno, nem usar a versão colorida sobre superfície escura — mede 1,95:1 e desaparece.

Cores

Clique em qualquer amostra para copiar o hex. Todo neutro tem subtom verde — não existe cinza neutro neste sistema, e trocar por um cinza puro descaracteriza a marca visivelmente.

Marca

Neutros

Status

Cada status é um par: um valor para o tema escuro, outro para o claro. Status nunca é comunicado só por cor — sempre acompanha ícone ou palavra.

Rampa de dados

Limitação conhecida: sob protanopia três séries não adjacentes se aproximam. Toda legenda nomeia a série COM o valor — o rótulo é o que carrega o sentido, não a cor.

Para desenvolvedores

O par temático

A decisão que organiza todo o sistema: o verde de marca não é uma cor, são duas. Nenhum verde único passa em contraste nas duas superfícies.

O erro mais comum do sistema

Rótulo branco sobre #46a239 mede 2,87:1 e reprova. A polaridade de text/on-brand INVERTE entre temas — nunca a fixe em branco.

Tipografia

Plus Jakarta Sans carrega todo o sistema. Space Mono existe só para código. Sukhumvit Set — a face das diretrizes impressas — é vetor de logo e impressão, nunca texto vivo na web.

Aa Bb Cc 0123

Dois valores parecem erro e não são

heading/3 tem tracking POSITIVO de +2px, e label/tag tem +20px. Ambos confirmados como intencionais — não normalize.

Espaçamento e grid

Base 4px. A escala dobra até 64 e depois vira irregular — essa cauda é ritmo de seção, não espaçamento de componente. Nunca use 3xl dentro de um card.

Formas e raios

Cantos modestos. Botões usam 8px, não pílula — só badge, tag, avatar e spinner são totalmente redondos. Cantos modestos comunicam precisão técnica; a pílula comunica leveza de consumo.

Acessibilidade

WCAG 2.1 AA em toda superfície, web e e-mail. Não é um checklist posterior — é a restrição que definiu a paleta. 196 pares auditados, zero reprovações no sistema construído.

Três exceções documentadas

Accent Neon como texto claro (bloqueado por escopo de token) · border/subtle como hairline decorativo · text/disabled sob a isenção WCAG 1.4.3 para controles inativos.

Marcadores de IA

A assinatura de governança da marca. Toda peça tocada por IA declara essa procedência — visivelmente, e nunca só por cor. A palavra é obrigatória: é o que torna o marcador legível para quem não distingue as cores, e o que o torna auditável.
